# Accounting Fundamentals & Financial Reporting — Excel

Repository ini berisi latihan pribadi saya dalam mempelajari dasar-dasar akuntansi secara praktis menggunakan Microsoft Excel.

Project ini dibuat sebagai bagian dari proses belajar untuk memahami bagaimana transaksi bisnis dicatat, diposting, disesuaikan, hingga menghasilkan laporan keuangan.

## Tujuan

Saya menggunakan project ini untuk membangun pemahaman akuntansi dari sisi praktik, bukan hanya menghafal konsep debit dan kredit.

Beberapa hal yang saya latih:

- Analisis transaksi
- Jurnal umum
- Posting ke buku besar
- Neraca saldo
- Jurnal penyesuaian
- Neraca saldo setelah penyesuaian
- Laporan laba rugi
- Laporan perubahan modal
- Neraca / laporan posisi keuangan
- Penggunaan Microsoft Excel dalam proses akuntansi

## Fokus Pembelajaran

Project ini masih merupakan learning project, sehingga fokus utamanya adalah memahami proses dan logika akuntansi.

Saya juga menggunakan Excel untuk memahami bagaimana setiap transaksi memengaruhi:

- Aset
- Liabilitas
- Ekuitas
- Pendapatan
- Beban

Selain itu, saya mulai menggunakan formula Excel untuk membantu proses perhitungan dan pengecekan saldo.
